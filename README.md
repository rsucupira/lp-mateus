# LP — Mateus Alexandre Ciantra

Landing page profissional, responsiva e estática.

## Estrutura

- `index.html`: conteúdo e metadados
- `styles.css`: identidade visual e responsividade
- `script.js`: menu móvel e animações leves
- `assets/`: fotografias otimizadas e favicon

## Publicação com GitHub Pages

Em **Settings → Pages**, selecione:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

A URL esperada será:

`https://rsucupira.github.io/lp-mateus/`
